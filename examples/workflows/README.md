# Optional client workflows

These Markdown files describe ways to use the server's tools. Each `SKILL.md` contains a name, description, and procedure. They are examples to install or load in your chosen client; this directory is not an automatic registration mechanism.

| Workflow | Purpose |
| --- | --- |
| [dnd5e-grounding](dnd5e-grounding/SKILL.md) | Use tool results and cite rules |
| [dnd5e-prep](dnd5e-prep/SKILL.md) | Prepare characters, places, and encounters |
| [parse-module](parse-module/SKILL.md) | Turn a module into linked notes and check its graph |
| [solo-dm](solo-dm/SKILL.md) | Run a session and save state |

The procedures currently use Chinese for narration and notes. They require a connected MCP client and are separate from the Python-only offline demonstration.
